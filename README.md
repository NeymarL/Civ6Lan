# Civ6 LAN · 最小桌面版

Windows / macOS 的文明6 Steam 版异地局域网助手。接入本机 ZeroTier One，真实创建私人虚拟以太网、申请加入、批准或撤销成员、查看虚拟 IP、查看已知直连路径、导出诊断、启动游戏。

这是早期功能原型，不包含虚拟网卡驱动；首次使用可在 App 内自动下载官方 ZeroTier One 安装包并打开系统安装程序，无需手动访问下载网站。没有人数为 2 的限制，目标至少 3 人；Windows/macOS 混合文明6实战尚需多人验收。网络就绪仅表示组网配置成功，不表示游戏已联通。

## 本机运行

当前已生成的测试产物：`dist/mac-arm64/Civ6 LAN.app`（Apple Silicon Mac）、`dist/Civ6-LAN-0.2.1-mac-arm64.zip`、`dist/Civ6-LAN-0.2.1-win-x64.zip`（完整解压后运行 `Civ6 LAN.exe`）。Mac App 已进行启动冒烟检查；Windows 便携版仅完成打包，尚未实机运行。均未做正式签名。

建议 Node.js 22 LTS 或更新版本。Electron 的运行时独立于系统 Node。

```sh
npm ci
npm start
```

## 三人试用

1. 三台电脑分别打开 App，点击“自动下载安装”。App 从官方固定版本地址下载 ZeroTier One 1.16.2，显示进度，校验 SHA-256 和系统发布者签名后打开 PKG/MSI 安装程序。按系统提示完成安装、管理员授权和网络权限确认。无需手动访问下载网站。已有可用服务会直接复用。
2. 安装期间保持 App 打开；它会重新检测服务。取消系统安装或安装失败后，可点“安装后重试”解除等待，再重新下载。不能读取服务令牌时点击“授权连接”。macOS 会弹出系统管理员授权，只读取本机 ZeroTier 令牌，应用自身不以管理员身份运行。
3. Windows 如不能自动连接，先运行 ZeroTier One 托盘应用，使其生成用户令牌，再重试。也可由电脑管理员读取 `C:\ProgramData\ZeroTier\One\authtoken.secret`，在本应用展开“输入本机 API Token”粘贴。用户令牌通常在 `%LOCALAPPDATA%\ZeroTier\One\authtoken.secret`。不要分享令牌，不要输入 Central 云端令牌。令牌只保留在进程内存，不进入房间文件和诊断。
4. 房主创建房间，将 `CIV6-` 开头的邀请码发给两位朋友。
5. 朋友输入邀请码申请加入，再将 App 显示的本机设备 ID 发给房主。房主核对后逐一批准。邀请码是网络 ID，不是鉴权密码；未知设备不会自动获准。
6. 等三台电脑均显示“网络就绪”并获得虚拟 IP。在文明6中进入“多人游戏 → 局域网”；一人创建游戏，其余两人加入。
7. 测试开始对局、至少进行若干回合、保存退出并重载。再分别测试 Windows 和 Mac 当游戏房主。

房主电脑的 ZeroTier 服务充当网络控制器，需要持续运行；不需要自购云服务器，但仍依赖 ZeroTier 公共根节点/可能的中继。电脑休眠或服务关闭会影响成员加入、配置续期和连接。

关闭 App **保留网络**，重新打开会恢复房间。“退出房间”会断开本应用加入的网络；房主退出还会删除该网络并使朋友失去授权，下次需创建新房间和邀请码。应用不修改其他已存在的网络。卸载 App 前先退出房间，或者在 ZeroTier 中手动退出对应网络。

## 无法发现文明6房间

- 核对三人的游戏版本、规则集和 MOD；组网不能修复游戏兼容性。
- 查看朋友是否等待授权，房主 ZeroTier 是否在线；允许文明6和 ZeroTier 通过系统防火墙，不要关闭整个防火墙。
- 检查是否与已有 VPN/本地地址段冲突。原型会随机选择一个私有 /24 网段并避开房主已使用的接口；尚未自动检测所有朋友的路由冲突。可退出重建网络再试。
- 网络有 IP 但看不到游戏，仍可能是游戏选择网卡、广播、路由或防火墙问题；当前原型不自动修改接口优先级、不保证解决全部房间发现问题。
- “存在直连路径”是已知 ZeroTier 对等路径状态；没有活跃路径不能直接证明正在中继。非房主仅显示房主控制器路径，不声称列出全体成员或准确在线人数。
- 导出诊断包含设备 ID、虚拟 IP、网络 ID 和路径状态，发给别人前确认这些信息可以分享，不包含 API Token。

## 自动下载安装说明（0.2.1）

- 用户点击后才下载，仅允许 `download.zerotier.com` 的 HTTPS 地址和同域重定向。固定版本、SHA-256 和发布者校验，校验失败不会启动安装。
- 支持下载进度、取消、5 分钟超时、失败临时文件清理和重新下载。系统安装确认及网络扩展授权仍须本人完成。下载成功不代表安装成功；App 检测到可用的本机服务后才提示就绪。
- 安装包暂存在应用用户数据目录的 `installers` 文件夹，成功打开后保留供系统安装器读取；不与 App 安装包一起分发。
- 自动安装流程的官方 Mac 下载、文件哈希和系统签名已实测；本次没有覆盖安装既有 ZeroTier。Windows 安装交互、安装后首次授权和三人混合平台联机仍需实机验收。

## 0.2.1 连接修复

改为每次请求前读取 ZeroTier 的 `zerotier-one.port`，支持自定义端口与服务重启后的端口变化，不再把非 9993 端口误报为服务未启动。仅在文件不存在时回退到 9993；文件无效或不可读时明确报错。授权按钮增加连接中的反馈。
